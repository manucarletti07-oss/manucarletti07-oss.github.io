# Portfolio de Manu Carletti

Portfolio personal de desarrollador web junior, publicado con GitHub Pages.

🌐 **Web:** [manucarletti07-oss.github.io](https://manucarletti07-oss.github.io)

## Contenido

- Inicio, sobre mí, proyectos, habilidades y contacto
- Modo claro y oscuro
- Diseño adaptable a móvil, tableta y ordenador
- [Documento de diseño](https://manucarletti07-oss.github.io/diseno.html)

## Tecnologías

HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons 1.11.3 y JavaScript.

## Estructura

- `index.html`: página principal
- `404.html`: página de error personalizada
- `diseno.html`: documento de diseño
- `css/estilos.css`: tema propio
- `js/main.js`: modo claro y oscuro
- `capturas/`: capturas del portfolio y del perfil
